# Suporte+ — novo site institucional

Landing page da Suporte+ (TI 24/7 para restaurantes, Fortaleza/CE).

- `index.html` — página única (HTML, CSS e JS sem dependências; fontes do Google Fonts)
- `img/` — logo, fotos e capas dos depoimentos
- `video/` — depoimentos de clientes em vídeo (comprimidos)

Para ver localmente, abra o `index.html` no navegador. Para publicar, ative o GitHub Pages na branch `main` (pasta raiz).
